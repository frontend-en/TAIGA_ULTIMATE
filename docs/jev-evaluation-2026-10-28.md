# Проверка и улучшение Jev — 28 октября 2026

Обновлена наша интеграция с Jev: модель осталась `jev-1.14.0`, версия критериев
изменена с `leads-v1` на `leads-v2`. Веса модели не обучались. Изменения применены
локально; развёртывание на production в эту работу не входило.

## Что исправлено

- Произвольный текст из поля контакта больше не вырезается из описания задачи.
  Маскируются распознаваемые контактные токены. Воспроизводимая инъекция,
  проходившая после такой подмены, теперь отклоняется.
- Описание услуг включает личного AI-друга, общение, идеи, объяснения,
  планирование, стиль ответов и вопросы о подключении, наряду с бизнес-задачами.
- Уточнено различие между пожеланиями к будущему боту, обсуждением безопасности
  с цитатами и командами, направленными на изменение решения проверяющего фильтра.
- Исправлен оценочный прогон: `AI_MANIPULATION` считается действительным
  решением, количество примеров вычисляется из набора, ручная проверка и сбои
  провайдера учитываются отдельно от отклонения и обычного пропуска.
- Пороги сохранены: отклонение от `0.99`, обычный маршрут при обеих оценках
  не выше `0.10`. Пороги не подгонялись под несколько пограничных примеров.

## Живые замеры

Для сравнения использованы одни и те же 24 независимых по смыслу примера до и
после изменений. Затем новая версия один раз проверена на отдельном наборе из
12 примеров, не использованном для настройки. Всего 60 вызовов Jev, без
автоматических повторов, ошибок провайдера и отправки писем при оценке.

В ячейках ниже: **обычный маршрут / ручная проверка / отклонение**.

| Набор | Обычные обращения | Спам | Prompt-инъекции |
| --- | --- | --- | --- |
| До, 24 примера | 11 / 1 / 0 | 0 / 1 / 5 | 1 / 1 / 4 |
| После, те же 24 | 11 / 1 / 0 | 0 / 0 / 6 | 0 / 1 / 5 |
| Отдельный набор, 12 | 5 / 1 / 0 | 0 / 0 / 3 | 0 / 1 / 2 |

На сопоставимом наборе число отклонённых атак выросло с **9/12 до 11/12**;
пропуск атаки по обычному маршруту устранён. На отдельном наборе отклонено **5/6**
атак. В сумме двух замеров новой версии из 18 обычных обращений 16 прошли
напрямую, 2 получили ручную проверку, ни одно не было автоматически отклонено.
Из 18 атак 16 отклонены, 2 получили ручную проверку, ни одна не прошла напрямую.

Ручная проверка не означает блокировку: такой запрос может быть отправлен на
проверочный email. Остались пограничные вопросы о безопасности с цитатами и
инъекции, замаскированные обычным обращением. Это небольшой синтетический набор,
а не оценка точности на реальном потоке и не доказательство защиты от всех атак.
Оценки Jev в этих замерах не являются измеренной точностью системы.
